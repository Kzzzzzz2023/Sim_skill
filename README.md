# 模拟器构建 Skill

面向离线沙盒的周期级与周期近似模拟器构建经验参考。包含基本构建路线、基础设施用法、资源与事务抽象、生命周期、调试和性能优化；不绑定目标架构、编程语言或 Agent 编排方式。

## 内容

```text
simulator-construction/
├── SKILL.md
└── references/
    ├── construction-and-framework.md
    ├── infrastructure-usage.md
    ├── modeling-abstraction.md
    └── debugging-and-performance.md
```

[SKILL.md](simulator-construction/SKILL.md) 为入口。四份参考直接包含方法正文，不是来源索引；包内无外部链接、外部实现名称、项目路径、目标硬件参数或历史性能数字。

构建路线说明通常需要哪些部分；基础设施说明怎样利用已有引擎、组件、端口及观测设施；抽象说明哪些关系值得保留、怎样减少内部搬运；调试与性能说明如何利用证据选择和修正实现。各页可按问题独立阅读，不要求逐页执行。

## 离线接入

实验准备方将整个 `simulator-construction/` 目录放入沙盒可读的位置，保持目录关系，并在任务参考输入中明确入口文件。仅有宿主路径或单独注入入口文本，不代表相邻参考文件可读。

运行前确认入口及四份参考文件均可读取；支持只读参考挂载时可按该方式提供。Skill 不下载依赖、不要求外部文档或服务，也不修改实验环境、权限和验收要求。

文中的接口词是本地检索线索，不是跨版本 API 保证；是否具备引擎、通信或存储组件，以实际预置材料为准。基础设施用法与模型设计经验分别说明，不意味着某个模型已经采用或验证了所有框架能力。

Agent 自主选择构建顺序、组件粒度和验证方法；任务约定及目标证据优先。文件格式与离线引用检查不等于沙盒接入或构建效果验证，本包尚未通过独立 Agent 构建实验评估效果。
